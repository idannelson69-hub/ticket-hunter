# מדריך התקנה

המערכת צריכה לרוץ על **שרת בענן** כדי לעבוד 24/7 גם כשהמחשב שלך כבוי.
ההמלצה: שרת וירטואלי קטן (למשל Hetzner Cloud CX22, בערך 4–5 € לחודש, מערכת Ubuntu 24.04).

זמן משוער: 45–60 דקות בפעם הראשונה.

---

## שלב 1 — מפתח Ticketmaster (חינם, 5 דקות)
1. היכנס ל-https://developer.ticketmaster.com ולחץ **Get Your API Key** / הרשמה.
2. אחרי האישור: **My Apps** ← האפליקציה שנוצרה ← העתק את **Consumer Key**.
3. זה הערך של `TICKETMASTER_API_KEY`.

> המכסה החינמית: 5,000 בקשות ביום. המערכת מחשבת לבד את התדירות המותרת
> (עם שתי הופעות — בדיקה כל ~44 שניות לכל היותר). לכן יעד של 10–30 שניות **לא מותר** במכסה הזו, והמערכת לא תחרוג ממנה.

## שלב 2 — בוט טלגרם (5 דקות)
1. בטלגרם, חפש **@BotFather** ושלח `/newbot`. בחר שם ושם משתמש לבוט.
2. BotFather ישלח **טוקן** (מחרוזת ארוכה עם נקודתיים). זה `TELEGRAM_BOT_TOKEN`.
3. פתח את הבוט החדש ושלח לו הודעה כלשהי (למשל "שלום").
4. את `TELEGRAM_CHAT_ID` תמצא אחרי ההתקנה: בממשק ← **הגדרות** ← **איתור מזהה הצ'אט שלי**.

## שלב 3 — שרת בענן
1. צור שרת Ubuntu 24.04 אצל ספק ענן והעתק את כתובת ה-IP שלו.
2. **דומיין** (נדרש ל-HTTPS): אפשר דומיין משלך, או חינמי מ-https://www.duckdns.org (למשל `my-tickets.duckdns.org`).
   הפנה אותו לכתובת ה-IP של השרת.
3. התחבר לשרת (ב-Windows: PowerShell):
```bash
ssh root@כתובת-השרת
```
4. התקן Docker:
```bash
curl -fsSL https://get.docker.com | sh
```
5. העתק את תיקיית הפרויקט לשרת (מהמחשב שלך, בחלון PowerShell חדש, מתוך תיקיית `projects`):
```bash
scp -r ticket-hunter root@כתובת-השרת:/opt/
```
   (אין צורך להעתיק את `.venv`, `node_modules` ו-`browser-profile` — אפשר למחוק אותן מהעותק לפני ההעתקה.)

## שלב 4 — הגדרות
בשרת:
```bash
cd /opt/ticket-hunter
cp .env.example .env
nano .env
```
מלא: `ADMIN_PASSWORD` (סיסמה חזקה), `SESSION_SECRET`, `TELEGRAM_BOT_TOKEN`, `TICKETMASTER_API_KEY`, `DOMAIN`.
ליצירת `SESSION_SECRET`:
```bash
python3 -c "import secrets;print(secrets.token_urlsafe(32))"
```
שמירה ב-nano: ‏Ctrl+O, Enter, Ctrl+X.

## שלב 5 — הפעלה
```bash
docker compose up -d --build
```
אחרי 1–2 דקות היכנס ל-`https://הדומיין-שלך` והתחבר עם הסיסמה.

## שלב 6 — חיבור טלגרם ובדיקה
1. בממשק: **הגדרות** ← **איתור מזהה הצ'אט שלי** ← העתק את המספר.
2. בשרת: `nano .env` ← הדבק ב-`TELEGRAM_CHAT_ID` ← שמור.
3. הפעל מחדש:
```bash
docker compose up -d
```
4. בממשק: **הגדרות** ← **שליחת התראת בדיקה**. ודא שההודעה הגיעה לטלפון.
5. סמן ב-**הכנה** את "התראת בדיקה בטלגרם התקבלה".

## פקודות שימושיות
מצב השירותים:
```bash
docker compose ps
```
יומן השרת:
```bash
docker compose logs -f --tail=100 app
```
עדכון אחרי שינוי קבצים:
```bash
docker compose up -d --build
```
גיבוי בסיס הנתונים:
```bash
docker compose cp app:/data/tickets.db ./backup-tickets.db
```

## הרצה מקומית במחשב (לבדיקה בלבד)
המחשב חייב להישאר דלוק כדי שהניטור יעבוד — לכן זה רק לבדיקה.
```bash
cd backend
../.venv/Scripts/python -m uvicorn app.main:app --port 8765
```
ואז לפתוח http://localhost:8765. ההגדרות המקומיות נמצאות ב-`backend/.env` (נוצר אוטומטית עם `DEMO_MODE=true`).

## מסייע הרכישה המקומי (אופציונלי)

```bash
.venv/Scripts/python -m pip install playwright
```
```bash
.venv/Scripts/python -m playwright install chromium
```
