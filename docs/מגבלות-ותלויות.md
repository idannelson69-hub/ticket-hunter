# מגבלות ותלויות חיצוניות

## מגבלות — חשוב לדעת

1. **אין מלאי מושבים בזמן אמת מ-Ticketmaster.** ה-API הציבורי (Discovery API) נותן קיום אירוע, סטטוס מכירה,
   מועדי מכירה וטווח מחירים, אבל לא אילו מושבים פנויים. ממשק המלאי שמור לשותפים מסחריים.
   לכן "תוצאות חיפוש" מגיעות מהזנה ידנית שלך (מה שראית באתר) — והמערכת מסננת ומדרגת אותן.

2. **אין רכישה אוטומטית (סל/קופה).** תנאי השימוש של Ticketmaster ושל רוב אתרי הכרטיסים אוסרים בוטים לרכישה,
   והאתרים מוגנים בתור וירטואלי ו-CAPTCHA. המערכת פועלת במצב **רכישה ידנית מודרכת**: קישור ישיר, העדפות,
   ההצעה המובילה, ועצירה לפני תשלום. כלי ה-Playwright המקומי רק פותח את העמוד בדפדפן שלך.

3. **תדירות בדיקה.** יעד של 10–30 שניות אפשרי רק כשהמקור מתיר:
   - Ticketmaster API: מוגבל במכסה היומית (5,000) — עם 2 הופעות לכל היותר בדיקה כל ~44 שניות.
   - עמודי אינטרנט רשמיים (Live Nation, oasisinet): לכל היותר פעם ב-5 דקות, ובכפוף ל-robots.txt.
   - TicketOne, Vivaticket, Ticketmaster.it (עמודי אתר): לא נסרקים אוטומטית — יש בהם הגנות בוטים ותנאי שימוש שאוסרים זאת.
     אם אתר חוסם — המערכת שולחת "נדרשת פעולה ידנית" ולא מנסה לעקוף.

4. **זיהוי מצב מעמודי אינטרנט מבוסס מילות מפתח** (למשל "On sale soon", "Sold out", "Buy tickets").
   אם אתר משנה ניסוח — הזיהוי עלול לפספס. בגלל זה יש כמה מקורות לכל הופעה, והתראה גם על שינוי מועד.

5. **"offsale" ב-Ticketmaster אחרי פתיחת המכירה** מתפרש כ"אזל" — זו הסקה, לא הצהרה רשמית של האתר.

6. **מכירות מוקדמות של Stray Kids (18.11)** דווחו בתקשורת בלבד. הן מוצגות ככאלה, בלי ספירה לאחור ובלי תזכורות,
   עד שיופיעו במקור רשמי (למשל ב-Ticketmaster API — ואז המערכת תתריע ותתחיל ספירה לאחור).

7. **Oasis — Roma אזל.** הדרך הרשמית היחידה היא Resale דרך Ticketmaster ו-Twickets, שלפי האתר הרשמי ייפתח
   רק קרוב למועד ההופעה. המערכת עוקבת אחרי עמוד הבית הרשמי ו-Ticketmaster ותתריע על שינוי.
   מחירי המקור שפורסמו בתקשורת התחילו בכ-92€ — כך שתקציב 150€ לכרטיס אפשרי רק בקטגוריות הזולות.

8. **Twickets** — אין להם ממשק ציבורי. בדיקה ידנית בלבד.

9. **בעיית SMS ישראלי** — מחוץ לשליטת המערכת. יש לבדוק מול התמיכה הרשמית של Ticketmaster Italia.

10. **לא נבדק בפועל:** קובצי Docker לא הורצו במחשב הפיתוח (Docker אינו מותקן בו). הקוד עצמו נבדק ורץ מקומית.
    בפריסה הראשונה בענן יש לוודא ש-`docker compose up -d --build` מסתיים בהצלחה.

## תלויות חיצוניות

| תלות | למה | עלות |
|---|---|---|
| שרת ענן (Ubuntu + Docker) | פעולה 24/7 | ~4–5 €/חודש |
| דומיין (או DuckDNS) | HTTPS | חינם / ~10 €/שנה |
| Telegram Bot API | התראות | חינם |
| Ticketmaster Discovery API | סטטוס ומועדי מכירה רשמיים | חינם (5,000 בקשות ביום) |
| Let's Encrypt (דרך Caddy) | תעודת HTTPS | חינם |
| Live Nation Italia, oasisinet.com | עמודים רשמיים למעקב | — |
| Playwright + Chromium (אופציונלי, מקומי) | פתיחת עמוד הרכישה בדפדפן | חינם |

## אבטחה — מה כבר מוגדר
- סיסמאות וטוקנים רק בקובץ `.env` (לא בקוד, לא ב-Git, לא ב-Docker image).
- אין שום שדה לפרטי אשראי במערכת.
- כניסה לממשק בסיסמה, עוגיית סשן חתומה (HttpOnly, SameSite=Strict, Secure ב-HTTPS), נעילה אחרי 5 ניסיונות כושלים.
- HTTPS אוטומטי דרך Caddy, כולל HSTS.
- טוקנים מוסתרים בלוגים; לוג פעולות בלי פרטים רגישים.
- מחיקת נתונים מהממשק (היסטוריה / הכול).
- השרת רץ בתוך Docker כמשתמש לא-root.
