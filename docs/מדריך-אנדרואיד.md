# מדריך הפעלה באנדרואיד

## 1. התראות טלגרם — שלא תפספס אף אחת
1. התקן **Telegram** מ-Google Play והתחבר.
2. פתח את הבוט שיצרת ← שלוש נקודות ← **התראות** ← הפעל, ובחר צליל בולט.
3. הגדרות הטלפון ← **אפליקציות** ← Telegram ← **סוללה** ← **ללא הגבלה** (אחרת אנדרואיד עלול לעכב התראות).
4. אם יש מצב "נא לא להפריע" — הוסף את Telegram לחריגים, לפחות בימי המכירה.
5. מומלץ: נעץ את הצ'אט עם הבוט (לחיצה ארוכה ← נעיצה).

## 2. הממשק כאפליקציה במסך הבית
1. פתח **Chrome** בטלפון והיכנס לכתובת המערכת (`https://הדומיין-שלך`).
2. התחבר עם הסיסמה.
3. שלוש נקודות ← **הוספה למסך הבית** / **התקנת אפליקציה**.
4. מעכשיו יש אייקון "צייד כרטיסים" שנפתח כמו אפליקציה.

## 3. ביום המכירה
- **שעה לפני:** בדוק בממשק שהנורית "המנוע פעיל" ירוקה, ושכל סעיפי **הכנה** מסומנים.
- התחבר מראש לחשבון Ticketmaster באפליקציה או ב-Chrome בטלפון. ודא שאימות ה-SMS עובד.
- **כשמגיעה התראה:** לחץ על הקישור בהודעה ← היכנס לתור אם יש ← בחר כמות ומושבים לפי ההודעה.
- **לפני תשלום:** בדוק את הסכום הכולל (כולל עמלות) מול התקציב: Stray Kids עד 600€, Oasis עד 300€.
- את התשלום והאימות מבצעים רק אתה. המערכת לא מבצעת תשלום בשום מצב.
